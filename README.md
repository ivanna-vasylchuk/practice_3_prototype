# Use-case 2 · Прийняття замовлення — HTML-прототип

## Як відкрити
Двічі клацніть `index.html` — прототип відкриється в браузері.
Інтернет не потрібен: шрифт Montserrat лежить у папці `fonts`.

## Як показувати на захисті
- **«Далі за сценарієм →»** — проходить основний шлях по кроках:
  сповіщення → заявки → деталі → вибір часу → прийнято → телефон клієнта → кандидати → підтверджено → «Клієнт обрав вас».
- **Список «Екрани»** ліворуч — перехід одразу на будь-який екран, зокрема розширення (3а, 6б, 7а, 7б).
- **Плашка над телефоном** показує, чий зараз телефон: майстра (темна) чи клієнта (блакитна).
- Усе в телефоні клікається так само, як у справжньому застосунку.

## Структура
```
index.html      — усі екрани (кожен — <section data-screen="...">)
css/style.css   — кольори, шрифт, кнопки, картки (вгорі — змінні з палітрою)
js/app.js       — переходи, анімації, дані для демо
img/            — фото несправності (photo1–3.svg) і мапа (map.svg)
fonts/          — Montserrat
```

## Що легко змінити
| Що | Де |
| --- | --- |
| Назву застосунку в сповіщеннях | `js/app.js`, рядок `const APP_NAME = 'Сервіс виклику майстрів';` |
| Кольори | `css/style.css`, блок `:root` на початку |
| Імена, рейтинги, відгуки майстрів | `js/app.js`, об'єкт `MASTERS` |
| Тексти заявок | `js/app.js`, об'єкт `REQUESTS`, і самі тексти в `index.html` |
| Фото несправності | покладіть свої фото в `img/` і замініть `photo1.svg` на назву свого файлу в `index.html` |

Після змін — збережіть файл (Ctrl+S) і оновіть сторінку в браузері (F5).
