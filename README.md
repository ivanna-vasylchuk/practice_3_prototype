# Use-case 2 · Прийняття замовлення

HTML-прототип для практичної роботи 3 — «Сервіс виклику побутових майстрів».

**▶ Відкрити прототип:** https://ivanna-vasylchuk.github.io/practice_3_prototype/

Працює в будь-якому браузері, на комп'ютері й на телефоні. Нічого встановлювати не треба.

---

## Як дивитися

- **«Далі за сценарієм →»** — проходить основний шлях по кроках:
  сповіщення → заявки → деталі → вибір часу → прийнято → телефон клієнта → кандидати → підтверджено → «Клієнт обрав вас».
- **Список «Екрани»** ліворуч — перехід одразу на будь-який екран.
- **Плашка над телефоном** показує, чий зараз телефон: майстра (темна) чи клієнта (блакитна).
- Усе в телефоні клікається, як у справжньому застосунку.
- **«Почати спочатку»** — скидає все до першого екрана.

## Що в прототипі

| № | Екран | Чий телефон |
| --- | --- | --- |
| 1 | Сповіщення про нову заявку | майстра |
| 2 | Нові заявки (фільтр «Сантехніка · Оболонь») | майстра |
| 3а | Нових заявок немає | майстра |
| 3 | Деталі заявки: фото, опис, мапа, прихований телефон | майстра |
| 4 | Орієнтовний час | майстра |
| 5 | Заявку прийнято | майстра |
| 6 | Заявка недоступна | майстра |
| 7 | Сповіщення клієнту, «Мої заявки» | клієнта |
| 8 | Кандидати (3 майстри) | клієнта |
| 8а | Профіль майстра | клієнта |
| 9 | Заявка підтверджена | клієнта |
| 10 | Чат з майстром | клієнта |
| 11 | Клієнт обрав вас (телефон клієнта відкрився) | майстра |
| 11б | Клієнт обрав іншого майстра | майстра |

**Розширення з практичної 2:** 2а — з push одразу в деталі · 3а — заявок немає · 6а — «Ігнорувати» · 6б — без часу кнопка неактивна · 7а — заявку скасовано · 7б — обрано іншого.


## Структура

```
index.html      — усі екрани (кожен — <section data-screen="...">)
css/style.css   — кольори, шрифт, кнопки, картки (вгорі — змінні з палітрою)
js/app.js       — переходи, анімації, дані для демо
img/            — фото несправності й мапа
fonts/          — Montserrat
```

## Що легко змінити

| Що | Де |
| --- | --- |
| Назва застосунку в сповіщеннях | `js/app.js` → `const APP_NAME` |
| Кольори | `css/style.css` → блок `:root` на початку |
| Імена, рейтинги, відгуки майстрів | `js/app.js` → `MASTERS` |
| Тексти заявок | `js/app.js` → `REQUESTS` і тексти в `index.html` |
| Фото несправності | покласти фото в `img/` і замінити назву файлу в `index.html` |
